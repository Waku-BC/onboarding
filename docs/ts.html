Reference summary

This workbench is loosely modeled after Brightcove’s debugger concepts: attach to a player, listen to player events, capture console-style information, and expose media data in one place.

official docs inspired

Useful debugger concepts

Brightcove’s Player Debugger captures player events, media information, and console-style diagnostics during playback. It attaches itself to the player and logs activity in real time.

Debug mode patterns

Brightcove’s docs describe enabling debug mode with data-debug for advanced embed code and ?debug for standard iframe code. This page maps those same ideas into a single troubleshooting surface.

Why this page differs

This is not an onboarding page. It is tuned for investigation, so it surfaces IDs, URLs, embed mode, player status, media metadata, event logs, and a copyable diagnostics payload.
